RAGA — GANG 51
Rotaract Club of Coimbatore Institute of Technology
=====================================================

HOW TO OPEN
Just open index.html in any browser. No build tools or server required.
(For the events dropdown / active-page highlighting to work correctly,
all files should stay together in the same folder as listed below.)

FOLDER STRUCTURE
RAGA-GANG51/
├── index.html          Home page
├── council.html        Full council grid (20 placeholders)
├── avenues.html        9 avenues of service
├── directory.html      9 office-bearer contacts
├── gallery.html        Masonry gallery + lightbox
├── contact.html        Contact page
├── event1.html         Club Service Events
├── event2.html         Community Service Events
├── event3.html         Professional Service Events
├── event4.html         International Service Events
├── event5.html         Special Events
├── style.css           All styling (royal blue + gold theme)
├── script.js           Navbar/footer injection + all interactivity
└── assets/
    ├── logos/          RAGA theme logo, CIT logo
    ├── board/          Board & council member photos
    ├── events/         Event posters (named e.g. club-poster-1.jpg)
    ├── gallery/         Gallery photographs
    ├── icons/          Any extra icons you want to add
    └── music/          Reserved for future audio assets

WHAT'S SHARED ACROSS PAGES
The navbar, footer, and floating musical decorations are generated by
script.js and injected into every page automatically via:
  <div id="site-navbar"></div>
  <div id="site-footer"></div>
  <div id="floating-decor"></div>
To change a nav link or footer detail everywhere at once, edit script.js
(see the NAV_LINKS array and buildFooter() function) rather than each page.

PLACEHOLDERS STILL TO FILL IN
- RAGA theme logo               → assets/logos/ (referenced from index.html hero)
- CIT logo                       → assets/logos/cit-logo.png
- Group photograph                → replace the placeholder block in index.html
- RaC CIT description paragraphs  → index.html "RaC CIT" section
- Rotaract Prayer text            → index.html prayer card
- Theme logo description text     → index.html theme section
- Board member photos & names     → index.html Board Members section (4 cards)
- Council member photos & names   → council.html (20 cards)
- Avenue descriptions              → avenues.html
- Directory names & photos         → directory.html
- Event descriptions & posters     → event1.html – event5.html
- Gallery images                   → gallery.html (assets/gallery/)
- Social media links                → script.js buildFooter(), and contact.html
- Phone numbers & email             → script.js buildFooter(), and contact.html

Until real images are added, broken image placeholders automatically
display a dashed gold border box (handled in script.js, initImageFallbacks)
so the layout never looks broken while you're filling in content.
